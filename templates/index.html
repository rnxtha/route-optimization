How the algorithms work
🟢 A* ⭐ Optimal (RECOMMENDED)

Uses heuristic (Haversine "as-the-crow-flies" to goal) + ML traffic edge weights. Explores far fewer nodes than Dijkstra, guaranteed to find the fastest route avoiding predicted-congested roads.

🔵 Dijkstra Baseline

Expands equally in all directions from start using distance-only weights. Guarantees the shortest geometric path, but ignores traffic — often takes you straight through crowded city roads.

🧠 ML Traffic Predictor

Every edge is scored by an ML model using road class, time-of-day rush windows, intersections/lane count, stable per-road historic effect, and stop-sign delay → produces predicted minutes + congestion level.
